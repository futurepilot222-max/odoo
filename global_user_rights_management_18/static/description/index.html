Access Rights Studio

Centralized access control for roles, menus, fields, records and actions

Odoo 18.0   Native security sync

One place to manage every permission

Access Rights Studio gives administrators a single, structured workspace to control who can see and do what in Odoo. Every setting stays in sync with Odoo's native security engine — groups, access rights, record rules and menu visibility — while field-level restrictions and a full audit trail live in a dedicated layer.

Key Features

Roles & User Rules

Build reusable roles backed by native security groups, or grant one-off permissions directly to a user.

Model Access (CRUD)

Set read, write, create and delete rights per model with clear, centralized control.

Action Controls

Allow or block export, import, print, archive, share and duplicate actions.

Menu Visibility

Show or hide menus by role or user so each person sees only what they need.

Field-Level Security

Restrict read and write access on individual fields, enforced on top of Odoo.

Record Rules

Limit visibility by scope: own, team, department, company, assigned or global.

Audit Log

Every permission change is recorded for full traceability and compliance.

Built-in User Guide

An in-app guide under Access Management explains every feature, right where you work.
